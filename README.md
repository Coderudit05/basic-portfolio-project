# Basic Portfolio Landing Page

A static portfolio website concept built with HTML and CSS. The page demonstrates a common personal-portfolio layout with navigation, a hero section, profile/about content, work, skills, and contact-oriented sections.

## Features

- Navigation links to page sections
- Hero section with primary and secondary calls to action
- About section and highlight statistics
- Portfolio, skills, and contact sections
- External Google Fonts and remote sample imagery
- Styling maintained in a separate CSS file

## Tech Stack

- HTML5
- CSS3
- Google Fonts

## Run Locally

No package installation is required.

```bash
git clone https://github.com/Coderudit05/basic-portfolio-project.git
cd basic-portfolio-project
```

Open `index.html` in a browser or use VS Code Live Server.

## Important Customization Note

The current page contains the sample identity **Alex Morgan** and example experience/project claims. Replace all sample identity details, statistics, images, and claims with accurate information before using or showcasing this as a real portfolio. The contact area is a front-end demonstration unless connected to a working submission service.

## Learning Goals

- Structure a multi-section landing page
- Style layouts with CSS
- Use anchor links for in-page navigation
- Organize content into reusable visual sections
- Practice typography, spacing, and responsive styling
